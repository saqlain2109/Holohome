# 🏠 Holohome - Smart IoT Home Automation Hub

> ⚡ **Tech Stack**: Python 3, Flask / Django REST Framework, WebSocket Hardware Controller  
> 🔌 **Capabilities**: Centralized device dashboard, appliance status telemetry, automated scheduling

---

## 🌟 Overview
**Holohome** is an IoT backend and management hub engineered in Python. It coordinates connected smart home devices, telemetry monitoring, scheduling rules, and RESTful API endpoints for smart appliances.

---

## 🚀 Key Features

- 💡 **Device Control Engine**: Real-time toggling and dimming for lighting, thermostats, and security locks.
- 📡 **Telemetry & Event Logging**: Historical metrics for energy consumption, device uptime, and trigger events.
- 🔐 **Secure REST APIs**: Token-protected endpoints for mobile and web frontend integration.
